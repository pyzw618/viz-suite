# 测试夹具

## `客服满意度_原始脏数据.csv`

用于 Stage 1 Gate 1 与回归测试的合成脏数据（非真实用户数据），UTF-8 with BOM，372 行 × 7 列。

**故意注入的问题**

| 问题 | 规模 | 用于验证 |
| :--- | :--- | :--- |
| 全空行 | 3 行 | 空行剔除与 `rows_dropped` |
| 完全重复记录 | 8 行 | `DROP_DUPLICATES` 与口径声明 |
| 满意度评分缺失 | 33 行（另含 3 行全空） | 缺失剔除、有效 n、误差棒 |
| 超长中文渠道名 | 最长 36 个显示单位 | 自动横排、左边距计算 |
| 响应时长以文本存储、含千分位 `1,205` | 1 行 | 数值文本警告与强制转换 |
| 高基数受访者编号 | 361 个唯一值 | 高基数文本警告 |
| 备注列 54% 缺失 | 约 198 行 | 缺失率 >30% 警告、分组候选过滤 |
| 季度标签 `2024Q4` 等 | 3 个 | 季度识别为有序分类而非时间戳 |

**列**

- `调研渠道`：6 个长中文标签；
- `城市`：6 个城市；
- `季度`：2024Q4 / 2025Q1 / 2025Q2；
- `满意度评分`：1–5，含缺失；
- `响应时长_分钟`：数值，含缺失与文本化异常；
- `受访者编号`：唯一 ID；
- `备注`：自由文本，多缺失。

生成脚本不随仓库分发；固定随机种子 20261025，可稳定复现相同分布特征（不是逐字节一致）。

## `经营实验_渠道月度.csv`

Stage 3 Gate 3 的同一份经营/实验数据（合成）：2025 年 1–6 月 × 4 渠道，24 行。
字段：`月份`、`渠道`、`收入_万元`、`目标_万元`、`新客数`、`满意度`、`A样本量`、`A转化数`、`B样本量`、`B转化数`。

- academic：按渠道汇总 A/B 转化率差与 95% CI；
- bi：收入/目标/新客/满意度 KPI 与筛选联动；
- story：各渠道月度收入堆叠与 6 月焦点标注。
