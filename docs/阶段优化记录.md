## Stage P0 · 止血与松绑（2026-10-26）

### 一、解决的核心问题

1. **标题/副标题/图例硬编码坐标碰撞（直接修复 `test-run` 翻车点）**
   - 原 28 套配方全部将标题写死在 `fig.text(0.015, 0.965, ...)`、副标题写死在 `fig.text(0.015, 0.918, ...)`，轴外右上图例写死在 `bbox_to_anchor=(1.0, 1.01~1.02)`。当真实业务副标题超过 ~32 个中文字符（如山雾咖啡 `fig-01`）时，副标题与右上图例发生严重像素重叠。
   - 原 `audit_export.py` 仅检查四周页边距（`cropping`），无法感知画布内部文本重叠或边缘局部裁切。
2. **“只改 PARAMS”教条与 `check_recipe_fidelity.py` AST 死锁**
   - 原 `viz-python/SKILL.md` 强制规定“只改顶部 `PARAMS` 块”，且 `check_recipe_fidelity.py` 对 `ax.*` 调用次数与关键字做严格比对（不一致即返回非零退出码阻断交付），导致 Agent 在面对真实业务数据时不敢改写分组排序、数据透视、复合参考线或动态面板布局（例如 `test-run` 中横轴写明“按上半年营收合计降序”，实际柱体却因 `SORT_X` 仅支持自然序而未按总额排序）。
3. **四套 `viz-scene-*` 与渲染引擎代码脱节**
   - 原 `tokens.json` 与 `viz_style.py` 未接入 `scene="academic|bi|story|geo"`，切换学术出版场景时仍保留商业汇报式大标题并浪费顶部约 20% 画布高度，也未自动联动单/双栏物理尺寸（`89mm` / `183mm`）、字号层级与横向/纵向标签预算。

### 二、关键改造清单

#### 1. 流式排版避让与 Agg Renderer 像素级碰撞自检
- **`skills/viz-python/scripts/viz_style.py`**
  - 新增 `wrap_text_units()`、`add_header()`、`adjust_layout()` 与 `_auto_reflow_figure()`：
    - 基于中英文显示宽度（CJK=2, ASCII=1）与画布实测宽度自动折行超宽标题/副标题，防止行首孤立标点与右边缘裁切；
    - 自动计算多行页眉下沿，当轴外图例或子图标题与页眉在水平+纵向发生冲突时，动态下调 `subplots_adjust(top=...)`；
    - 当 `in_canvas_title=False`（如 `academic` 场景）或标题为空时，自动隐藏顶栏标题并将 `top` 回收至 `0.93`，释放顶部 20% 空白；
    - 新增左边缘刻度/轴标签防裁切与底部 `source` 页脚防碰撞自动微调；
    - 升级 `pick_orientation()` 为物理画布宽度感知（结合 `_planned_width_mm` 与刻度字号估算水平标签总预算，单栏 `89mm` 下长中文标签自动切换横向条形）。
  - 新增 `check_text_collisions(fig)` 与 `last_layout_audit()`：
    - 调用 Agg `Renderer` 提取全图可见文本（`fig.texts`、轴内外 `Legend`、`ax.title`、`xlabel/ylabel`、视口内主刻度标签、`ax.texts`/`Annotation`）的精确像素包围盒（`get_window_extent`），检测两两像素重叠与画布四边裁切；
    - 在 `save_figure()` 导出 PNG 时将审计摘要写入 PNG `tEXt` 元数据块 `viz_layout_audit`。
- **`skills/viz-audit/scripts/audit_export.py`**
  - 在 `audit_png()` 中解析 `viz_layout_audit` 元数据，新增 `text_collision` 与 `text_clipped` 两项 `blocking` 级别确定性质检（存在重叠或裁切时返回 `verified=false` 且进程退出码为 `1`）。

#### 2. 解除 AST 死锁：升级为三区弹性适配契约与非阻断 Review Hints
- **`skills/viz-python/scripts/check_recipe_fidelity.py`**
  - 默认改为**非阻断审查提示模式**（`non_blocking: true`，退出码恒为 `0`，输出 `verdict: "pass" | "review_hints"`；仅显式传入 `--strict` 时才以非零码退出）；
  - 新增真正高价值的退化提示：`bootstrap_removed`（移除 `vs.bootstrap`）、`banned_cmap`（引入 `jet/rainbow/hsv` 禁用色图）、`interactive_show`（调用阻塞式 `plt.show()`）。
- **`skills/viz-python/SKILL.md` & `AGENT.md`**
  - 废除“只改 `PARAMS`”硬约束，确立**三区弹性适配契约**：
    1. **数据管道区（自由改写）**：允许按业务口径自由改写过滤、聚合、透视、总额排序（如 `SORT_X = "total_desc"`）与缺失处理；
    2. **画布与布局区（弹性伸缩）**：允许调整 `WIDTH_MM`、`ASPECT`、`GridSpec`、参考线与注释层，配合 `vs.add_header` / `vs.adjust_layout` 自动避让；
    3. **微质感保护区（默认保留）**：保留 `vs.bootstrap`、实心边线+浅填色（`fill_alpha=0.22`）、去顶右脊线、tabular 刻度与全中文/双语标签体系。
  - 将写死的宿主工具名 `ViewImage` 改为宿主无关的“多模态读图工具（如 `read_file` / `ViewImage`）”。

#### 3. 打通四场景代码级预设（`scene="academic|bi|story|geo"`）
- **`skills/viz-core/assets/tokens.json` & `skills/viz-python/scripts/viz_style.py`**
  - 在 `tokens.json` 中新增 `"scenes"` 预设字典（`academic`、`bi`、`story`、`geo`），涵盖色板、布局族、`in_canvas_title`、默认单栏/双栏宽度（`89mm`/`183mm`、`160mm`、`254mm`、`180mm`）、宽高比、字号档位（`small`/`regular`/`large`）与导出规格；
  - `resolve_theme(scene=...)` 与 `bootstrap(..., scene=...)` 完整打通优先级：`CLI/overrides > 项目 EXTEND.md > 用户 EXTEND.md > figure-manifest.json > scene 预设 > tokens 默认值`；
  - 全部 28 套配方统一支持 `SCENE` 参数与 `--scene {academic,bi,story,geo}` 命令行参数，多面板/宽表配方在 `--scene academic` 下自动选用双栏 `183mm`。

#### 4. 原生 28 套配方隐患清零与目录预览图同步更新
通过新上线的 `check_text_collisions()` 扫描原始 28 套黄金底稿，额外揪出并修复了 3 套底稿的原生隐藏碰撞与 2 套体验细节：

- `stacked_bar_total_line.py`：原生支持 `SORT_X = "total_desc" | "total_asc"` 按堆叠总额排序；
