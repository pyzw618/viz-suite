# 证据分级与诚实报告

逆向工程的第一原则：**证据强度决定交付承诺**。不要用“看起来像”替代可复核证据。

## 一、四级定义

### SOURCE（源码级）

适用：

- 本地 HTML/SVG/旧图表源码；
- ECharts `getOption()`、Chart.js `config`、Plotly `_fullData`/`data`；
- SVG 中带 `data-value/data-x/data-y/data-row/data-col` 等元数据。

承诺：

- 精确原始数据；
- 精确图表结构/系列/颜色；
- 对应栈的可运行代码；
- 可标注“SOURCE：来自页面配置/源码”。

不允许：

- 把从 DOM 推断的“近似值”标成 SOURCE；
- 执行未知页面脚本、绕过登录/付费墙。

### PARTIAL / B（像素标定级）

适用：

- ≥800px 的清晰位图；
- 柱/条、折线、散点/气泡、饼/环、矩阵热力；
- 有可读刻度/图例；轴线清晰。

承诺：

- 带置信度的估算 CSV；
- 干净图目标 MAPE ≤5%；
- 可运行复现代码 + SSIM/ΔE/IoU + diff。

不允许：

- 把低清/压缩图当 B；
- 把 3D/透视/实拍当 B；
- 为凑 SSIM 修改数据。

### C（结构骨架级）

适用：

- 低清、强压缩、聊天窗口纯图片、无本地路径；
- 箱线/小提琴细节、复杂网络/桑基；
- 无配置可读的网页/图表截图。

承诺：

- 可编辑代码骨架；
- 样式 Token；
- 明确标注 `TODO` 的占位/近似数据；
- `precision_claimed=false`。

不允许：

- 把 C 级近似值包装成精确数据；
- 不写 warning 就输出 CSV。

### X（诚实拒绝）

适用：

- 3D 透视柱/饼、实拍扭曲照片、手绘艺术图、动态视频帧；
- 任何无法从 2D 像素唯一恢复比例的图。

承诺：

- 说明物理不可逆原因；
- 仅提供 2D 规范化重构代码建议；
- 不输出数值 CSV。

不允许：

- 从椭圆饼图硬猜扇区比例；
- 从 3D 柱图反推高度；
- 把阴影/透视当数据。

## 二、降级触发器

| 条件 | 动作 |
| :--- | :--- |
| 宽度 <800 px | B → C |
| Laplacian 方差 <18 | B → C（模糊） |
| 轴拟合 R² <0.98 | B → C 或 partial |
| 缺少刻度且无法可靠补全 | B → C |
| 饼图椭圆 aspect >1.22 | B → X |
| 3D/透视/手绘/视频 | X |
| 无可读配置的页面 | C |
| 复杂网络/桑基/分布细节 | C |

## 三、报告模板

```text
通道：SOURCE / B / C / X
证据：<配置/文件/DOM/像素测量说明>
数据：<CSV 路径>；行数；估算/精确
轴：<scale, R²>；<像素→数值映射>
误差：<MAPE 中位数/最大值>；<仅当有 ground truth 打分时>
往返：SSIM=…；ΔE=…；IoU=…；diff=…
局限：<重叠点/截断/低清/3D/无图例/未读刻度>
```

- `SOURCE` 可直接说“精确”，但注明来源与版本。
- `B` 必须说“估算”，给出误差；没有 ground truth 时说明“未做外部误差评估”。
- `C` 必须说“骨架/TODO”，不得给精确数字。
- `X` 必须说明拒绝原因，并给出 2D 重构建议。

## 四、No-Compensation 检查

在每轮 SSIM 修正后问：

1. 我改的是数据，还是样式/轴/布局？
2. 改动是否有视觉或几何证据？
3. 是否为了让分数好看而平滑曲线/加偏移？
4. 原图是否有截断基线等误导设计？如有，是否同时给出“忠实复刻版”和“诚实零基线建议”？

任何“数据让步”都必须撤回。

## 五、示例

### SOURCE

```text
通道：SOURCE（ECharts option，页面内嵌 JSON）
数据：A=12, B=18, C=9, D=24, E=15（精确）
结构：bar / xAxis category / series Revenue
代码：reproduction.js（同一 option）
```

### B

```text
通道：B（1000×700 清晰图）
轴：x 分类；y 线性 R²=0.99999
数据：bar_data.csv（5 行，估算）
误差：中位 0.19%，最大 0.54%（与已知基准对照）
往返：SSIM=0.949，ΔE=1.50，layout IoU=1.00
局限：柱顶抗锯齿导致 ≤0.6% 偏差
```

### C

```text
通道：C（420px 低清图）
数据：仅结构骨架；刻度未检出，使用均匀位置近似
承诺：不精确；precision_claimed=false
建议：重新导出 ≥800px 原图后再做 B 级
```

### X

```text
通道：X（3D/透视饼图，椭圆 aspect=1.99）
结论：扇区角度被透视压缩，不可逆
交付：拒绝数值反推；仅给 2D 饼/条形重构建议
```
