# 选型决策树（Decision Tree）

按顺序回答，命中即停；最后一步给出「首选 + 备选 + 禁忌」三件套。

## 第 0 步：先排除不该画的图

- 只有 1 个数字、没有比较对象 → 用**大数卡（stat card）**，不要画单柱。
- 数据是流程/层级/架构，不是数量 → 用流程图/树图，交给信息图或技术图，不要强行统计图。
- 需要精确查表而非看趋势 → 用表格，图只做概览。

## 第 1 步：数据里有没有时间维？

**有**（连续日期/时间戳）：

1. 1 条序列 → 折线图；需要强调累计 → 面积图。
2. 2–5 条序列 → 多线折线 + 尾端直接标注；只在 1 条焦点线加粗。
3. >5 条序列 → 高亮 1–2 条 + 其余冷灰，或拆小多图。
4. 有不确定性 → 多层置信带；有事件 → 事件竖线 + 顶部批注。
5. 需要比较期初期末排名 → 凹凸轨迹图；只有两期 → 斜率图。

**没有**，进入第 2 步。

## 第 2 步：主要问「分布」还是「汇总值」？

**分布**（同一分类下有大量观测）：

1. n ≥ 20 且分组 ≤6 → **雨云图**（半小提琴 + 箱体 + 散点）。
2. 分组 7–12 → 箱线 + 抖动散点；分组 >12 → 只画箱线或小提琴。
3. 单变量 → 直方图 + 中位数线；需要比较形状 → 叠加密度曲线（≤3 条）。
4. 两方法配对 → Bland–Altman；不要只报相关系数。

**汇总值**，进入第 3 步。

## 第 3 步：比较的是「大小」「构成」还是「关系」？

**大小/排名**：

1. 单分类 + 数值 → 排序条形图；标签长 → 横排。
2. 两个分类 + 数值 → 分组条形图 + 误差棒；只有两组 → 哑铃图。
3. 多指标排名 → 棒棒糖图 / 点区间图 / 坡度图。
4. 需要展示到目标的差距 → 子弹图（BI 场景）。

**构成**：

1. 总和有意义且 ≤5 段 → 堆叠条形图（横向优先）。
2. 需要看占比随时间变化 → 100% 堆叠面积。
3. 分类 ≤6 → 环图可以，但排序条形图通常更好。
4. 多层级构成 → 桑基图或树图；不要嵌套双环。

**关系**：

1. 两个数值 → 散点 + 回归/LOESS；点多 → 二维密度或六边形分箱。
2. 三个数值（大小编码）→ 气泡图，面积映射数值而非半径。
3. 多个数值 + 分类 → 平行坐标 / 相关矩阵 / 小型多图。
4. 源-汇流量 → 桑基图；单链路转化 → 漏斗图。

## 第 4 步：能不能在同一坐标系融合？

满足以下任一条件时优先融合，而不是拆图：

- 两个编码回答同一个问题（如柱 + 误差棒、堆叠柱 + 总量线）；
- 分布与汇总需要同时出现（散点 + 箱线/半小提琴）；
- 趋势与不确定性需要同时出现（折线 + 置信带）。

融合层数 ≤3，每层信息不重复；超过则拆成共享轴多面板。

## 第 5 步：是否需要多面板？

- 同一指标按分类拆分 → 小多图，共享轴、统一色板；
- 主图 + 边际分布 → 散点回归 + 双边际密度；
- 主图 + 辅助表 → 生存曲线 + 在险人数、校准曲线 + 预测分布；
- 矩阵 + 树 → 热力矩阵 + 行列聚类树。

## 第 6 步：输出三件套

```text
首选：<图种>，因为 <数据形态 + 意图>；系列 ≤N，标签预算 OK。
备选：<图种>，当 <条件变化> 时改用。
禁忌：<不要用什么>，因为 <误导风险>。
```
