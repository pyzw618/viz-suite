# 分级需求澄清指南（Intake）

目标：既不拿到数据盲目开画导致返工，也不把简单需求变成审问问卷。**任何时候最多追问 3 个问题，每题必须附默认推荐项。**

## 一、四档判定

| 输入完整度 | 判定标准 | Agent 行为 |
| :--- | :--- | :--- |
| **完整明确** | 已有数据、分析目的、受众/场景、期望输出形式 | 零追问。用 1 句话复述理解与默认设置，直接画像与渲染 |
| **局部模糊** | 只有「帮我画张图 / 做个看板 / 复刻这张图」 | 从下方问题库挑 **≤3 个**最关键问题，每题给默认推荐 |
| **缺失硬条件** | 无数据源、关键指标口径有歧义、地理图无 GeoJSON | **阻塞提问**：明确指出缺什么，绝不编造数据 |
| **用户要求跳过** | 「别问了 / 先按默认出一版」 | 立即按场景默认值执行，在交付说明底部列出全部默认假设 |

## 二、问题库（按信息缺口挑选，不逐条问）

1. **核心问题**：这张图要让读者回答什么问题？
   - 默认推荐：比较不同分组的差异，并标出不确定性。
2. **目标受众与场景**：论文审稿人 / 高管汇报 / 业务监控 / 公众传播？
   - 默认推荐：内部业务汇报（清晰优先，弱化装饰）。
3. **交付介质与物理尺寸**：期刊单栏 89mm / 双栏 183mm / 16:9 投影 / A4 / 网页？
   - 默认推荐：160mm 宽 PNG（300dpi）+ PDF，可直接嵌入报告。
4. **输出栈**：Python 静态图 / 单文件 HTML / 信息图 / 复刻现有图？
   - 默认推荐：Python 静态图（出版级、可复现）。
5. **数据口径**：指标定义、时间范围、缺失值处理、是否含异常值？
   - 默认推荐：剔除缺失值，图注标实际 n；异常值保留但用稳健统计。
6. **系列数与标签长度**：分类最多几个？最长标签几个字？
   - 默认推荐：分类 ≤8，系列 ≤5；长标签自动横排。
7. **逆向保真策略**（仅复刻任务）：要精确数据、可编辑代码，还是只要风格？
   - 默认推荐：先尝试源码级提取；无源码则像素标定并标注证据等级。

## 三、提问模板

> 为了把图做对，我需要确认 3 件事（括号内是默认值，回复「按默认」即可）：
> 1. 这张图主要回答什么问题？（默认：比较各渠道满意度差异）
> 2. 用在哪里？（默认：内部汇报，160mm 宽 PNG+PDF）
> 3. 缺失值和异常值怎么处理？（默认：剔除缺失、保留异常并在图注说明）

## 四、默认假设的写法

执行后必须在交付说明中显式列出，例如：

```text
默认假设：
- 缺失值按整行剔除（共 37 行），图中 n 为有效样本；
- 误差棒为 95% 置信区间（正态近似），样本量 <30 的分组已标注；
- 颜色取 Okabe-Ito 色盲安全序列，输出 160mm 宽、300/600dpi PNG 与矢量 PDF。
```

## 五、什么时候必须停下

- 数据文件不存在或所有列都不可解析；
- 指标口径存在两种以上合理解释且会改变结论（如「转化率」分母是访问还是点击）；
- 地理图缺合规 GeoJSON，或用户要求内置受限底图；
- 用户要求编造数据、伪造显著性或在图上直接写未经计算的 p 值。
