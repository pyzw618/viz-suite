## 2. 用户自备标准审图号 GeoJSON 接入约定

1. 若业务必须在真实行政区划边界上绘图（如省/市/区县精确边界），**必须由用户在 `<WORKSPACE>` 提供具备自然资源部合法审图号（GS 号）的标准 GeoJSON/TopoJSON**。
2. 渲染脚本须在图脚（`SOURCE`）显式标注：`审图号 / 底图来源 / 坐标系（如 CGCS2000 或 WGS84） / 投影方式`，并对无数据区域使用浅灰斜纹（`hatch="////"`）与 0 值区域严格区分。
