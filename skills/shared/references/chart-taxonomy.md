# 图表分类学与选型速查（Chart Taxonomy）

按 **分析意图 × 数据形态** 检索。先定意图，再定数据形态，最后检查系列数与标签预算。

## 一、意图 → 首选图种

| 意图 | 数据形态 | 首选 | 备选 | 禁止 / 慎用 |
| :--- | :--- | :--- | :--- | :--- |
| **比较分类大小** | 1 分类 + 1 数值 | 排序条形图（长标签横排） | 棒棒糖图、点图 | 饼图 >6 类；3D 柱 |
| **比较分组差异** | 2 分类 + 1 数值 | 分组条形图 + 误差棒 | 哑铃图（两组）、坡度图（时间前后） | 堆叠柱比较组间总量 |
| **构成/占比** | 1 分类 + 1 数值（总和有意义） | 堆叠条形图（≤5 段） | 100% 堆叠、环图（≤6 类） | 多环嵌套、3D 饼 |
| **时间趋势** | 时间 + 1~5 数值 | 折线图 | 面积图（强调累计量） | 时间当分类的柱状图；双 Y 轴 |
| **分布** | 1 分类 + 大量观测 | 雨云图 / 箱线 + 散点 | 小提琴、直方图、ECDF | 只画均值柱掩盖分布 |
| **相关性** | 2 数值 | 散点 + 回归/LOESS | 二维密度、六边形分箱 | 把相关写成因果 |
| **多指标对比** | 多数值 + 分类 | 平行坐标、雷达（≤6 维） | 热力矩阵、小型多图 | 雷达 >8 维、面积雷达 |
| **排名变化** | 时间 + 排名 | 凹凸轨迹图（Bump） | 斜率图（仅两期） | 折线交叉时无标注 |
| **流量/归因** | 源-汇-量 | 桑基图 | 漏斗图（单链路） | 桑基节点过多 |
| **地理** | 区域 + 数值 | 分级设色图 | 空间气泡、OD 流向 | 绝对总量直接着色面积 |
| **一致性/方法比较** | 两方法配对数值 | Bland–Altman | 散点 + 一致性界限 | 只报相关系数 |
| **效应量汇总** | 多研究/多指标 | 森林图 | 漏斗图（Meta） | 无置信区间的点估计 |

## 二、同坐标系图层融合（In-Axis Fusion）

单一坐标系内叠加互补编码，比拆成两张图更容易读出关系。**≤3 层**，每层必须承担不同信息。

| 融合组合 | 适用问题 | 关键约束 |
| :--- | :--- | :--- |
| 柱 + 误差棒 + 总体均值线 | 分组比较 + 不确定性 | 零基线；误差棒定义写进图注 |
| 堆叠柱 + 总量折线 | 构成 + 总量趋势 | 折线用深色，柱用浅填；标注总量单位 |
| 折线 + 多层置信带 | 趋势 + 不确定性 | 由深到浅递减透明度，最多 3 层 |
| 散点 + 箱线/半小提琴 | 分布 + 原始观测 | 白边散点；箱体窄于云宽 |
| 散点 + 二维 KDE 等高线 | 密集点云 | 点透明度 ≤0.5，等高线细而浅 |
| 柱 + 事件竖线 | 时间序列拐点 | 事件标注在顶部，避免压数据 |
| 点区间 + 汇总菱形 | 多指标效应量 | 区间线统一线宽，菱形白边 |
| 回归线 + 双边际密度 | 相关 + 边缘分布 | 边际图与主轴共享比例 |

## 三、共享轴多面板（Small Multiples）

- 同一指标按分类拆分：共享 Y 轴，面板按中位数排序；
- 散点回归 + 边际密度：主轴占 80%，边际图占 20%，用 `GridSpec` 的 `width_ratios/height_ratios` 对齐；
- 热力矩阵 + 行/列聚类树：树状图与矩阵共享顺序，矩阵留白 0；
- 生存曲线 + 在险人数表：共享 X 轴，下方表格高度固定；
- 校准曲线 + 预测分布：共享 X 轴，下方直方图不显示 Y 刻度。

## 四、系列数与标签预算

| 维度 | 安全上限 | 超限处理 |
| :--- | :--- | :--- |
| 分类色系列 | 8（推荐 2–5） | 合并「其他」、改用连续色阶、拆小多图 |
| 折线系列 | 5（直接标注优先） | 高亮 1–2 条焦点线，其余置灰 |
| 饼/环分类 | 6 | 改排序条形图或合并小类 |
| 图例项 | 7 | 直接标注、图内标签、交互筛选 |
| 最长标签 | 12 个显示单位且分类 >5 | 自动切换横向条形图；严禁 45° 斜排 |
| 热力图行列 | 30×30（屏幕）/ 15×15（印刷） | 聚合分箱、Top-N + 其他 |

**显示单位**：中文/全角字符按 2 计，拉丁字符按 1 计。`viz-core` 的 `profile_data.py` 会输出 `max_label_units`。

## 五、常见误用与替代

| 误用 | 为什么错 | 替代 |
| :--- | :--- | :--- |
| 饼图 10 个分类 | 人眼角度辨别差，小类不可读 | 排序条形图 |
| 截断 Y 轴柱状图 | 夸大差异，比例失真 | 零基线 + 差异标注 |
| 双 Y 轴 | 两条轴可任意缩放，制造伪相关 | 指数化到共同基准 / 拆两图 / 直接标注 |
| 3D 柱/饼 | 透视扭曲面积与角度 | 2D 版本 |
| 只用均值柱展示分布 | 掩盖双峰、异常与样本量 | 雨云图 / 箱线 + 散点 |
| 彩虹色连续热图 | 非感知均匀，误导梯度 | 单色顺序色阶 / 发散色阶 |
| 45° 斜排长标签 | 阅读效率极低 | 横向条形图 |
| 意面折线（>8 条） | 无法追踪单条线 | 高亮 + 置灰、小多图 |
| 以面积表示绝对总量（地图） | 大区域天然占优 | 密度/人均/比率 |
