# 视觉诊断清单（Audit Checklist）

本清单分两关：**第一关**由 `audit_export.py` 做确定性检查；**第二关**由你（多模态看图）按本文件逐项目检。两关都通过才能交付。

## 一、第一关：脚本检查项

| 检查 | 通过标准 | blocking 条件 |
| :--- | :--- | :--- |
| `blank` | 图像有可见内容 | 近似纯色（白屏/空图） |
| `dpi` / `dpi_min` | ≥300（印刷 ≥300，期刊 ≥600） | — |
| `physical_width` | 与目标宽度误差 ≤1% | — |
| `cropping` | 四周有安全边距 | 内容贴边且疑似裁切 |
| `white_margin` | 单侧空白 ≤30% | — |
| `wcag_contrast` | 正文 ≥4.5:1，大字号 ≥3:1 | <3:1 |
| `cvd_palette` | 色盲模拟最小 ΔE ≥10 | <6（色盲不可分） |
| `pdf_fonts` | 全部字体嵌入 | 任一字体未嵌入 |
| `pdf_content` | 有文本或图像 | 空白页 |
| `svg_external` | 无外部网络引用 | 存在外链 |
| `html_external` | 无外部资源 | 存在 CDN/外链 |
| `svg_text` | 文本保留为节点 | 文字全部转曲（warning） |

## 二、第二关：多模态目检项

按顺序检查，每项记录 `pass / warning / blocking` 与证据（截图区域）。

### A. 文字与字体

- [ ] **中文方块**：任意轴标签、图例、标题中出现 `□`/`▯` → **blocking**。
- [ ] **文字裁切**：标题/轴标签/来源注记被画布边缘切掉 → **blocking**。
- [ ] **文字重叠**：刻度标签互相压住、标题压副标题、数值标注压数据线 → **blocking**（严重）或 warning（轻微）。
- [ ] **字号层级**：标题 > 副标题 > 轴标题 > 刻度 > 来源；投影场景最小 14px。
- [ ] **负号/特殊符号**：`-`、`±`、`≥`、`%`、`‰` 显示正常。

### B. 数据与编码

- [ ] **零基线**：柱状/面积图 Y 轴是否从 0 开始；若截断，是否有明确断轴标记。
- [ ] **误差棒定义**：图注/SD/SEM/CI 是否可见。
- [ ] **样本量 n**：分组 n 是否可见；缺失剔除是否说明。
- [ ] **系列可辨识**：颜色 + 线型/标记双重编码；色盲模拟下仍可分。
- [ ] **过绘**：散点是否糊成色块；折线是否成为「意面图」；热力图标签是否可读。
- [ ] **排序**：分类是否按数值排序（除非有天然顺序）。
- [ ] **图例**：是否遮挡数据；项数 ≤7；能否改为直接标注。

### C. 布局与留白

- [ ] **长标签**：是否横排；有无 45° 斜排；是否被截断。
- [ ] **图例位置**：优先图外或空白区；不得压住数据。
- [ ] **边距**：标题与绘图区、绘图区与轴标签、来源注记之间不拥挤。
- [ ] **宽高比**：是否与目标介质匹配（16:9 / A4 / 期刊栏宽）。
- [ ] **移动端**（HTML）：390px 竖屏下主图是否可读；是否横向溢出。

### D. 诚实与叙事

- [ ] **标题**：写事实还是写未检验的因果/夸大结论。
- [ ] **来源与口径**：数据来源、统计口径、时间范围、缺失处理是否注明。
- [ ] **显著性**：星号是否有检验支撑；是否定义 `* p<0.05`。
- [ ] **视觉欺骗**：3D、双 Y 轴、面积映射总量、彩虹色阶是否存在。

## 三、分级处置

| 级别 | 定义 | 处置 |
| :--- | :--- | :--- |
| **blocking** | 数据失真、乱码、文字裁切/重叠、白屏、字体未嵌入、外链 | **必须回退修改并复检**，禁止带病交付 |
| **warning** | 可读性下降、版式不优、对比度偏低、n 未标注 | 记录并尽量修；交付说明中声明 |
| **info** | 参数已核对、无问题 | 无需处理 |

## 四、常见丑图改造范式

| 症状 | 根因 | 改造 |
| :--- | :--- | :--- |
| 满屏网格 + 粗边框 | 默认样式未清理 | 换 `soft_grid` / `clean_open`，网格 alpha 0.35 |
| 柱子像色块 | 纯色填充 | 浅填深边：alpha 0.18 + 同色描边 |
| 标签歪脖子 | 45° 旋转 | 横向条形图 |
| 图例像补丁 | 图例框 + 多列拥挤 | 去边框、直接标注、图外单行 |
| 数据像毛线团 | 散点无透明度/白边 | alpha 0.5 + 白边 0.3pt + 降采样 |
| 重点不突出 | 所有系列同权重 | 焦点主色 + 其余冷灰置灰 |
| 图很大字很小 | 画布与字号不匹配 | `plan_size` 反推字号或缩窄画布 |
| 颜色刺眼 | 高饱和纯色 | 语义色板 + `category_order` |
| 指标堆砌无结论 | 哑巴图表 | Action Title / 直接标注写洞察 |

## 五、复检闭环

```text
1. audit_export.py → 记录 blocking/warning
2. 宿主读图工具目检 → 记录证据区域
3. 修改 PARAMS 或代码 → 重新渲染
4. 重跑 audit_export.py + 目检
5. 仍有 blocking → 继续修；最多 3 轮，之后如实报告未解决项
```

**严禁**为了让指标通过而删掉数据、篡改比例或关闭检查项。

## 六、交付说明模板

```text
产物：<路径>
视觉结论：<一句话核心发现>
数据口径：<过滤、缺失、n、误差定义>
默认假设：<逐条>
验证状态：
- 物理/色彩脚本检查：通过（blocking 0 / warning N）
- 多模态目检：已完成 / 未完成（未完成必须声明）
- 未解决项：<blocking/warning 列表或“无”>
```
