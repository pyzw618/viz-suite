# 反模式清单（Anti-Patterns）

按严重度分级。`blocking` = 必须重绘后才能交付；`warning` = 应修但不阻塞。

## 一、统计诚实类

| 严重度 | 反模式 | 后果 | 修复 |
| :--- | :--- | :--- | :--- |
| **blocking** | 柱状图/面积图非零基线 | 差异被成倍夸大 | 强制零基线；需要看差异时改用点区间图并标注 |
| **blocking** | 编造数据、p 值、显著性星号 | 学术不端 | 只使用上游统计结论；没有检验就不画括号 |
| **blocking** | 随意拼凑双 Y 轴自由缩放 | 制造伪相关/伪交叉 | 优先拆分为共享 X 轴上下双面板或指数化同基准；**仅经典帕累托图（左轴数量+右轴 0–100% 累计占比）或物理强耦合量纲允许双轴，且左右轴标签/刻度须与对应序列颜色严格绑定** |
| **blocking** | 面积映射绝对总量（地图/气泡） | 大区域天然占优 | 转密度、人均、比率；气泡用面积而非半径 |
| **blocking** | 相关写成因果 | 结论越界 | 文案改为「相关/伴随」，不做因果断言 |
| **warning** | 只画均值柱不展示分布 | 掩盖双峰、异常与 n | 雨云图 / 箱线 + 散点 |
| **warning** | 误差棒未定义（SD/SEM/CI） | 读者无法解读 | 图注写明定义与样本量 |
| **warning** | 分类过多仍用饼图 | 小类不可辨 | ≤6 类；否则排序条形图 |
| **warning** | 缺失值悄悄剔除 | 样本量与口径失真 | 图注写 `rows_dropped` 与有效 n |
| **blocking** | 廉价伪 3D 柱/饼/透视环图 | 透视畸变扭曲比例 | 律改 2D 平面表达；**真三维空间场、响应曲面（z=f(x,y)）或三维帕累托前沿除外，但须提供等高线投影或清晰网格参照** |

## 二、可读性类

| 严重度 | 反模式 | 修复 |
| :--- | :--- | :--- |
| **blocking** | 中文显示为方块 `□□□` | 运行 `detect_fonts.py`，设置可用中文字体 |
| **blocking** | 文字裁切/重叠/出界 | 调整字号、边距、换行；长标签改横排 |
| **blocking** | 图例遮挡数据 | 移到图外、直接标注或调整绘图区 |
| **blocking** | 白屏/空图 | 检查数据过滤与坐标范围 |
| **warning** | 45° 斜排长标签 | 横向条形图 |
| **warning** | 意面折线（>8 条） | 高亮 1–2 条 + 其余置灰，或小多图 |
| **warning** | 网格线过强 | 浅灰 + 低 alpha，对比度 ≤15% |
| **warning** | 图例项 >7 | 直接标注或交互筛选 |
| **warning** | 字号 <6pt（印刷）/ <14px（投影） | 放大字号或缩小画布信息密度 |

## 三、色彩与无障碍类

| 严重度 | 反模式 | 修复 |
| :--- | :--- | :--- |
| **blocking** | 只用红绿区分正负 | 颜色 + 符号/箭头双编码 |
| **blocking** | 深底黑字 / 浅底白字 | `contrast_text()` 自动选择 |
| **warning** | 高饱和纯色（`#FF0000`/`#00FF00`） | 用语义角色或色板 |
| **warning** | 相邻色相区分系列（2–4 类） | 用 `category_order` 取最大差异色 |
| **warning** | Jet/Rainbow 连续色阶 | 顺序/发散感知均匀色阶 |
| **warning** | 色盲模拟下 ΔE <10 | 换色板或增加线型/纹理 |
| **warning** | 灰度打印不可辨 | 叠加线型、纹理、直接标注 |

## 四、结构类

| 严重度 | 反模式 | 修复 |
| :--- | :--- | :--- |
| **warning** | 同一任务输出两张同义主图 | 只保留一张主图，其余作补充 |
| **warning** | 多图色板/字体/尺寸不一致 | 用 `figure-manifest.json` 锁定 |
| **warning** | 一页塞入 >7 个要点 | 拆分或提高信息层级 |
| **warning** | 只有指标名、没有结论的「哑巴图表」 | 用 Action Title 或直接标注写出洞察 |
| **warning** | 用文生图冒充数据图表 | 所有含数值比例的图必须代码渲染 |

## 五、交付前自检 10 秒版

1. 中文有没有方块？—— 看任意轴标签。
2. 有没有文字互相压住或出界？—— 看最长标签与图例。
3. 柱子是不是从 0 开始？—— 看 Y 轴下限。
4. 误差棒/置信带有没有定义？—— 看图注。
5. 系列数是否超过色板上限？—— 看 `palette.pick(n)` 是否报错。
6. 灰度打印还能区分吗？—— 转灰度看一遍。
7. 数据来源、n、口径写了吗？—— 看左下角。
8. 同一实体跨图是否同色？—— 看 `series_color_map`。
9. 物理宽度与字号是否匹配目标介质？—— 看 `plan_size` 输出。
10. 是否声明了未执行的视觉验证？—— 看交付说明。
