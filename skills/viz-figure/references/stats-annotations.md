# 统计标注规范

## 一、误差棒定义（必须写进图注）

| 类型 | 公式 | 适用 |
| :--- | :--- | :--- |
| SD | `std(ddof=1)` | 描述样本离散度 |
| SEM | `SD / √n` | 均值标准误 |
| 95% CI（正态近似） | `1.96 × SEM` | n ≥ 30 的均值区间 |
| 95% CI（t 分布） | `t(0.975, n-1) × SEM` | n < 30；需 scipy 或查表 |
| IQR | `Q3 − Q1` | 稳健离散度，箱体使用 |

**硬规则**：

- 图上出现误差棒/误差带，图注必须写明是哪一种、样本量 n、是否剔除缺失。
- `n < 30` 时正态近似 CI 会偏窄；脚本会发出警告，交付说明必须声明。
- 不要用误差棒重叠与否推断显著性。

## 二、显著性括号

`viz_style.sig_bracket(ax, x1, x2, y, label)` 只负责画括号和文字，**不计算 p 值**。

```python
SIG_PAIRS = [
    {"a": "对照组", "b": "处理组", "label": "*"},      # 星号由上游检验给出
    {"a": "对照组", "b": "联合组", "label": "n.s."},
]
```

- 星号含义必须在图注定义（`* p<0.05, ** p<0.01`）；
- 多重比较需说明校正方法（Bonferroni / Holm / FDR）；
- 优先报告效应量与置信区间，不只放星号；
- 严禁为了「好看」补画不存在的显著性。

## 三、直接标注

- 系列 ≤5 时优先在尾端直接标注系列名，减少图例查找；
- 柱端数值标注仅在单系列或少量分类时使用，避免 18 个数字挤在一起；
- 标注文字颜色用 `text` 角色，背景复杂时加 `vs.annotation_box` 白底细边；
- 单位写在轴标题或首个刻度，不重复写在每个数值后。

## 四、样本量与缺失

- 每组 n 必须可见：刻度第二行、图例说明或图注；
- 缺失值剔除数量写入交付说明与 `*_data.csv`；
- 组内有效样本差异大时，不要用等宽柱暗示等权重；
- 真实零值、缺失值、剔除异常值必须在图注区分。

## 五、常见统计误导

| 误导 | 修正 |
| :--- | :--- |
| 柱状图非零基线 | 零基线；改点区间图看差异 |
| 均值柱掩盖双峰 | 雨云图 / 箱线 + 散点 |
| 双 Y 轴制造相关 | 指数化到共同基准或拆图 |
| 只报 p 值不报效应量 | 同时给效应量与 CI |
| 相关写成因果 | 改为「相关/伴随」 |
| 截断坐标轴夸大差异 | 保留完整轴 + 差异标注 |
| 用面积表示绝对总量 | 转密度/人均/比率 |
