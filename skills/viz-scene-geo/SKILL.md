# viz-scene-geo：地理空间差分

本 Skill 不重复渲染代码；由 `viz-python`（静态地图）或 `viz-web`（自包含 ECharts 地图）执行。它只覆盖 `viz-core` 的 12 个场景槽位。

## 一、何时使用

- 行政区划分级设色、区域经营/人口/健康指标地图；
- 空间气泡、OD 流向、区域对比与时间切片；
- 需要投影、坐标系、底图来源与分箱方法说明；
- GeoJSON 由用户提供且已审核合规。

不要用于：在线瓦片导航、需要实时路况的地图、未授权边界下载、把绝对总量直接映射为面积颜色。

## 二、标准工作流

1. **确认合规底图**：用户提供 GeoJSON；记录来源、版本、坐标系（WGS-84 / GCJ-02 / CGCS2000）与许可。缺失则阻塞，不擅自下载。
2. **确认指标**：区域、时间切片、核心指标、是否应转为密度/人均/占比；绝对总量不得直接着色面积。
3. **读 `scene-delta.md`**：套用 12 槽位；选择分级设色、空间气泡或 OD 流向。
4. **投影与长宽比**：按区域形状选择投影/长宽比；图例独立，不压地图。
5. **分箱**：顺序/发散色阶 ≤7 档；无数据区域固定浅灰斜纹；标注分箱方法（自然断点/分位数/等距）。
6. **渲染**：SVG 或自包含 HTML；行政区标签防碰撞抽稀；按需经纬网/比例尺。
7. **验收**：投影/坐标系/底图来源齐全；小区域可读；色盲与灰度可辨；无绝对总量误导。

## 三、缺省参数

| 项 | 缺省 |
| :--- | :--- |
| 画布 | 按区域长宽比自适应；图例独立区域 |
| 色阶 | 顺序 5–7 档；发散 7 档；无数据浅灰斜纹 |
| 字体 | 行政区标签 ≥9 px；防碰撞抽稀 |
| 辅助 | 按需经纬网、比例尺、指北针；无关边框隐藏 |
| 底图 | 用户提供 GeoJSON；强制标注来源/坐标系 |
| 交互 | 缩放平移、Hover 详情（HTML） |
| 导出 | SVG 或自包含 HTML/PNG |

## 四、必须检查

- [ ] 投影、坐标系、底图来源、版本、许可全部标注；
- [ ] 绝对总量未直接用于面积着色；已转密度/人均/比率；
- [ ] 分箱方法、档位与色阶类型写明；
- [ ] 无数据区域固定浅灰斜纹，不冒充 0；
- [ ] 小区域有排序条形图/标签辅助读数；
- [ ] 色阶 ≤7 档，色盲与灰度可辨；
- [ ] 标签不重叠、不裁切；图例不压地图；
- [ ] 不下载/分发未审核边界。

## 五、边界

- 不提供未经授权的行政边界或商业地图瓦片；
- 不把投影变形当成真实面积差异；
- 不用发散色阶表达单向量（除非有明确中点）；
- 不用面积大小直接表达总量而不做归一化。

详细 12 槽位见 `scene-delta.md`；地图渲染见 `viz-python/SKILL.md` / `viz-web/SKILL.md`。
