# geo · 12 槽位增量

> 基线：`viz-core` + `viz-python` / `viz-web`。这里只写覆盖规则，不复制渲染代码。

## 1. 标题范式

- 标题 = 区域范围 + 核心指标 + 时间切片。
- 例：“华东 2025 年 6 月门店密度：上海外环外显著高于内环”。
- 副标题写口径、单位、分箱方法；图例独立。

## 2. 画布比例

- 按区域长宽比自适应；不要强行拉成正方形。
- 图例独立区域，不压地图；图例、比例尺、来源分区摆放。
- 小区域多时，可加排序条形图辅助读数。

## 3. 色彩策略

- 顺序色阶（5–7 档）表达单向量；发散色阶（7 档）表达有明确中点的差异。
- 无数据区域固定浅灰斜纹；不要用 0 值颜色冒充缺失。
- 色盲安全；灰度打印可辨；不要用 Jet/Rainbow。
- 绝对总量不得直接着色面积；转密度/人均/占比/比率。

## 4. 字体字号

- 行政区标签 ≥9 px；防碰撞抽稀；必要时只标重点区域。
- 图例刻度清晰；单位与分箱说明同图例区。
- 手机端标签进一步抽稀，保留核心区域。

## 5. 坐标轴网格

- 按需展示经纬网、比例尺、指北针；无关边框隐藏。
- 投影与坐标系决定形状；不要混用不同投影的区域。
- 图例刻度与色阶一一对应；分箱边界可读。

## 6. 批注重点

- 数据统计分箱方法：自然断点 / 分位数 / 等距；写明档位。
- 异常区域、空白区域、边界变化单独标注。
- 空间气泡：面积编码数值，注明半径映射；OD 流向：线宽编码流量。
- 小区域用排序条形图辅助，不强行放大标签。

## 7. 偏好图种

- 分级设色（Choropleth）、空间气泡、OD 流向、区域小倍图。
- 区域对比优先排序条形图 + 地图组合；地图负责空间，条形负责精确读数。
- 不用 3D 地图、拉伸变形或装饰性光晕。

## 8. 交互粒度

- HTML：区域缩放平移、Hover 详情浮层、时间切片切换。
- 静态：多面板时间切片或小倍图；不要依赖 hover。
- 交互不得改变色阶分箱而不提示。

## 9. 交付格式

- SVG 或自包含 HTML/PNG；GeoJSON 由用户自备并随交付说明来源。
- 需要印刷时导出 PDF/SVG；需要网页时用本地 ECharts/GeoJSON。
- 附分箱表、色阶图例与数据来源。

## 10. 来源口径

- **强制标注**：地图投影、坐标系（WGS-84 / GCJ-02 / CGCS2000）、底图来源/版本/许可。
- 指标口径、时间切片、分箱方法、缺失区域处理。
- 不擅自下载、拼接或分发未审核边界。

## 11. 无障碍

- 色阶分级 ≤7 档；附排序条形图辅助小区域读数。
- 色盲与灰度可辨；不要只用颜色区分类别。
- 标签不重叠、不裁切；Hover 详情不能是唯一信息入口。

## 12. 专项禁令

- 严禁直接用绝对总量做面积着色（须转密度/人均/比率）。
- 严禁擅自下载未审核边界底图。
- 严禁 3D 地图、透视变形、装饰性光晕。
- 严禁把缺失值涂成 0 值颜色。
- 严禁不标投影/坐标系/底图来源。

## 渲染映射

- `viz-python`：GeoJSON + 投影；色阶用 `sequential_cmap`/`diverging_cmap`；无数据斜纹 hatch；标签抽稀。
- `viz-web`：本地 ECharts `map`/`geo` 组件 + 本地 GeoJSON；不引在线瓦片。
- 先做合规检查：GeoJSON 来源、坐标系、许可、版本。

## 验收清单

- [ ] 投影、坐标系、底图来源/版本/许可齐全。
- [ ] 绝对总量未直接着色面积。
- [ ] 分箱方法、档位、色阶类型写明。
- [ ] 无数据区域浅灰斜纹，不冒充 0。
- [ ] 小区域有排序条形图/标签辅助。
- [ ] 色阶 ≤7 档；灰度/色盲可辨。
- [ ] 标签不重叠、不裁切；图例不压地图。
- [ ] 未下载/分发未审核边界。
