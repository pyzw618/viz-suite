# viz-scene-story：汇报叙事差分

本 Skill 不重复渲染代码；可配合 `viz-python`（静态高清华丽图）或 `viz-web`（分步叙事）。它只覆盖 `viz-core` 的 12 个场景槽位。

## 一、何时使用

- 高管汇报、董事会材料、数据新闻、年度复盘；
- 需要一句话结论作为标题，而不是“指标名 + 时间”；
- 需要 16:9 宽屏（兼容 4:5 竖版），直接拖入 PPT；
- 需要单一焦点色 + 冷灰背景系列、直接标注、关键拐点事件。

不要用于：论文插图、实时监控大屏、需要精确交互筛选的分析工具。

## 二、标准工作流

1. **先写 Action Title**：用一句可被数据支持的话说明“发生了什么、为什么重要”，不写“收入趋势图”。
2. **确定单一主张**：一张图只回答一个问题；选一个焦点系列，其余置灰。
3. **读 `scene-delta.md`**：逐条套用 12 槽位；选择坡度图、哑铃图、高亮折线、排序条形。
4. **渲染**：16:9 或 4:5；最小字号 ≥14 px；标题为正文 1.5×；弱化轴线，直接标注。
5. **加注**：关键拐点事件气泡、差距倍数、来源与推演假设固定左下角。
6. **验收**：远距可读、单焦点清晰、无“哑巴图表”；导出 SVG/PNG 600 DPI 或分步 HTML。

## 三、缺省参数

| 项 | 缺省 |
| :--- | :--- |
| 画布 | 16:9（254×142.9 mm）；竖版 4:5（200×250 mm） |
| 标题 | Action Title，1.5× 正文，最多 2 行 |
| 色彩 | 单一焦点主色 + 其余冷灰（#CBD5E1）；背景白/浅暖 |
| 字号 | 最小 14 px；来源 11–12 px 可接受但需对比度 |
| 轴线 | 弱化或隐藏；直接标注优先 |
| 批注 | 关键拐点事件气泡、差距倍数、转折点 |
| 导出 | SVG + PNG 600 DPI；或分步叙事 HTML |

## 四、必须检查

- [ ] 标题是结论，不是指标名；
- [ ] 只有一个视觉主角；其余系列确实退到背景；
- [ ] 关键数值直接标在数据点旁，不依赖图例反查；
- [ ] 投影距离下最小字号 ≥14 px；
- [ ] 来源与推演假设固定在左下角；
- [ ] 不使用红绿作为唯一编码；
- [ ] 不把探索性监控表直接当汇报图；
- [ ] 每张图都能回答“所以呢？”。

## 五、边界

- 不为了戏剧性夸大差异；倍数、百分比必须可复核；
- 不隐藏不利数据或截断基线制造“增长”；
- 不把相关性写成因果；
- 不堆满 KPI 与装饰图标；一页只留一个中心论点。

详细 12 槽位见 `scene-delta.md`；渲染实现见 `viz-python/SKILL.md` 与 `viz-web/SKILL.md`。
