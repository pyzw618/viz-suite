# bi · 12 槽位增量

> 基线：`viz-core` + `viz-web`（优先）或 `viz-python`（静态汇总）。这里只写覆盖规则。

## 1. 标题范式

- 模块化短标题：`对象 + 指标 + 时间范围 + 状态`，例如“6 月收入 876 万元，目标完成率 104%”。
- 顶栏固定 As-of 日期、口径标签、单位、数据来源。
- 避免“经营驾驶舱”单独作标题；标题要带本期结论或状态。

## 2. 画布比例

- 12 列响应式栅格：顶栏 + KPI 行 + 主图/明细。
- 桌面 1280×800 一屏完整；手机 390 单列纵向滚动。
- 图表高度按预算：折线/环图 220 px，条形 200 px，KPI 紧凑卡 90–110 px。

## 3. 色彩策略

- IBCS：实际=实心；预算/目标=空框或虚线；预测=斜纹。
- 阈值：达标绿、临界琥珀、未达红；必须叠加文字/符号，不只靠颜色。
- 单一主色用于实际值；目标用中性灰；不要把每个 KPI 都染成不同颜色。

## 4. 字体字号

- 正文 12–14 px；KPI 大数 22–28 px；等宽数字（`font-variant-numeric: tabular-nums`）。
- 标题 18–22 px；手机 18 px。
- 数字右对齐；单位与数字同卡但字号更小。

## 5. 坐标轴网格

- 弱虚线水平网格；目标基准线用灰色虚线。
- 柱/条零基线；折线 y 轴从 0 起或明确标注缩放。
- 不使用双 Y 轴；量纲不同拆图。

## 6. 批注重点

- 同比/环比（YoY/MoM）箭头 + 数值 + 方向双重编码。
- 目标完成率 = 实际 ÷ 目标；没有目标就不画。
- 异常波动标记；说明异常原因或“待核查”，不静默剔除。

## 7. 偏好图种

- 子弹图、增减瀑布、漏斗、留存热力矩阵、迷你趋势线、实际 vs 目标折线/条形。
- KPI 卡 + 趋势 + 构成 + 明细表；一屏一个主问题。
- 避免满屏仪表盘与装饰性发光边框。

## 8. 交互粒度

- 跨图维度筛选联动（月份/渠道/区域）；时间粒度切换；Hover 十字准星。
- 单一 `state` 源；所有图从同一份过滤结果派生；空态提示。
- 筛选后副标题更新为当前口径。

## 9. 交付格式

- 离线自包含 HTML + 汇总 CSV + 1280×800 / 390×844 截图。
- 本地 vendor；零外部请求；`lint_html` + `check_layout` 通过。
- 汇总 CSV 包含收入、目标、完成率、新客、满意度等可复核字段。

## 10. 来源口径

- 标明 As-of 日期、数据截至时间、指标公式、去重规则、币种/单位。
- 目标/预算来源与版本；预测模型另行标注。
- 不把不同口径的指标放在同一 KPI 行。

## 11. 无障碍

- 键盘 Tab 可达筛选器；涨跌颜色 + 箭头/文字双重编码。
- 图表有 `aria-label`；表格有表头；对比度 ≥4.5:1。
- 手机端字号 ≥12 px；不依赖 hover 才能读取关键数值。

## 12. 专项禁令

- 严禁满屏无重点仪表盘与装饰性发光边框。
- 严禁双 Y 轴、3D、饼图 >6 类。
- 严禁用红色表示“坏”而不加文字说明。
- 严禁前端自行编造统计显著性。
- 严禁把不同时间窗/口径混在同一屏。

## 渲染映射（viz-web）

- 使用 `templates/dashboard/sales_dashboard.html` 或等价 12 列栅格；
- `--viz-focal` 实际值；目标色用中性灰；红黄绿只用于状态；
- 图表容器显式高度；`ResizeObserver` 重绘；
- 表格动态文本用 `textContent`；
- 截图：`capture_html.py --viewport desktop=1280x800 --viewport mobile=390x844`；
- 布局：`check_layout.py` 必须 0 issue。

## 验收清单

- [ ] 1280×800 页脚完整；390 无横向溢出。
- [ ] 每个 KPI 有公式与 As-of 时间。
- [ ] 实际/目标编码不同；红黄绿有文字/符号。
- [ ] 筛选联动一致，空态有提示。
- [ ] 表格数字右对齐、等宽。
- [ ] HTML 零外链；本地 vendor。
- [ ] 汇总 CSV 可复核。
