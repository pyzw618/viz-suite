# viz-scene-bi：商业经营看板差分

本 Skill 不重复渲染代码；优先由 `viz-web` 执行，静态汇总图可交 `viz-python`。它只覆盖 `viz-core` 的 12 个场景槽位。

## 一、何时使用

- 经营驾驶舱、周月报、渠道/区域监控、目标达成追踪；
- 需要 IBCS 语义：实际实心、目标空框/虚线、预测斜纹；
- 需要红黄绿阈值、同比/环比箭头、异常波动标记；
- 需要离线 HTML + 汇总 CSV + 桌面/手机截图。

不要用于：论文投稿图、故事型长图、无数据支撑的“大屏”、需要登录或后端查询的系统。

## 二、标准工作流

1. **定义指标与口径**：收入/订单/客单/转化/留存的计算公式、时间窗、去重规则、As-of 日期。
2. **确认对比对象**：目标、预算、去年同期、上月；没有目标就不要画“完成率”。
3. **读 `scene-delta.md`**：套用 12 槽位；选择 `viz-web` 看板模板或 `viz-python` 汇总图。
4. **搭数据层**：一份长表或聚合表作为唯一数据源；筛选状态只保留一个 `state`，所有图从同一份过滤结果派生。
5. **渲染**：12 列响应式栅格；KPI 行 + 主图 + 明细；图表高度按 1280×800 预算控制。
6. **验收**：`lint_html` 零外链；`check_layout` 1280/390 无溢出；CDP 截图；`ViewImage` 看 KPI 对齐、图例、表格与页脚。
7. **交付**：HTML + 汇总 CSV + 两张截图 + 口径说明。

## 三、缺省参数

| 项 | 缺省 |
| :--- | :--- |
| 画布 | 12 列栅格；桌面 1280×800 一屏，手机 390 单列纵向滚动 |
| 字体 | Inter / Microsoft YaHei；正文 12–14 px；KPI 大数等宽 |
| 色彩 | 实际=蓝实心；目标=灰虚线/空框；正向绿、负向红、预警琥珀 |
| 网格 | 弱虚线水平网格 + 目标基准线 |
| 图表高度 | 折线/环图 220 px；条形 200 px；KPI 紧凑卡 |
| 交互 | 月份/渠道/区域筛选联动，Hover 十字准星 |
| 导出 | 离线 HTML + 汇总 CSV + 1280/390 截图 |

## 四、必须检查

- [ ] 每个 KPI 都能追溯到公式与 As-of 时间；
- [ ] 实际与目标视觉编码不同（实心 vs 空框/虚线），不只靠颜色；
- [ ] 红黄绿只用于阈值状态，且带文字/符号双重编码；
- [ ] 1280×800 页脚完整；390 无横向溢出；
- [ ] 表格数字右对齐、等宽；空态有提示；
- [ ] 筛选后所有图同步更新，副标题反映当前口径；
- [ ] 不使用满屏仪表盘、发光边框、3D 装饰；
- [ ] 动态文本用 `textContent`，不拼 `innerHTML`。

## 五、边界

- 不把相关性写成因果；异常点要标注但不擅自剔除；
- 没有预算/目标就不画完成率与目标线；
- 不用双 Y 轴；量纲不同拆图或标准化；
- 不在前端做复杂统计推断；上游结论由分析/统计环节提供。

详细 12 槽位见 `scene-delta.md`；看板实现见 `viz-web/SKILL.md`。
