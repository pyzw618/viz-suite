# academic · 12 槽位增量

> 基线：`viz-core` 设计令牌 + `viz-python` 渲染。这里只写覆盖规则，不复制渲染代码。

## 1. 标题范式

- 图内**不放大标题**；标题信息交给图注。
- 子图左上/左下用 `a, b, c`，字号与正文字号一致或略大 1 pt。
- 图注格式：`图 1｜一句话结论。误差棒=95% CI；n=…；检验=…。数据来源：…。`
- 配方中把 `TITLE=""`、`SUBTITLE=""`，用 `viz_style.panel_label(ax, "a")` 加面板标号。

## 2. 画布比例

- 单栏：`WIDTH_MM=85–89`；双栏：`WIDTH_MM=175–183`。
- 高度按内容定，避免为凑高度留大片空白。
- 多面板共享轴时，面板间距小于图外留白；`fig.subplots_adjust` 明确设置。

## 3. 色彩策略

- 色板：Okabe-Ito / ColorBrewer 色盲安全；默认 `okabe_ito`。
- 黑白打印：叠加线型（实线/虚线/点线）、点型或纹理；不能只靠色相。
- 连续色阶：Viridis / Cividis 等感知均匀色阶；**禁用 Jet/Rainbow**。
- 同一实体跨面板同色；用 `figure-manifest.json` 的 `series_color_map` 锁定。

## 4. 字体字号

- Arial / Helvetica 或宋体 / 黑体；`font.family` 必须是有序回退列表。
- 正文 6–8 pt，图注 6–7 pt；标题（若期刊要求）不超过 8–9 pt。
- 线宽 0.5–1.5 pt；坐标轴线 0.5–0.8 pt；刻度朝外。
- 最小有效字号 6 pt；缩放到目标栏宽后仍须 ≥6 pt。

## 5. 坐标轴网格

- 经典 L 型（左/下）或闭合框；同一期刊内保持一致。
- 默认**无背景网格**；若期刊要求网格，用 0.3–0.5 pt 浅灰虚线。
- 柱/面积零基线；折线可按数据范围缩放，但须在图注说明。
- 对数轴明确标注底数；不要用双 Y 轴。

## 6. 批注重点

- 强制：样本量 `n`、误差棒定义（SD/SEM/95% CI）、检验名称与显著性阈值。
- 显著性括号只画上游检验给出的 p 值/星号；**不编造 p 值**。
- 缺失、剔除异常值、真实零值分开说明；不要静默删除。
- 效应量优先于单一 p 值；森林图给出点估计与 CI。

## 7. 偏好图种

- 云雨图、箱线+散点复合、森林图、火山图、UpSet、ROC、KM 生存曲线+风险表。
- 多面板：共享轴、统一色标、面板标号一致。
- 不为了“好看”叠加无关图层；一个面板只回答一个问题。

## 8. 交互粒度

- 纯静态印刷级交付；不依赖 hover 才能读取数值。
- 需要可编辑矢量时导出 SVG；需要投稿时导出 PDF。
- 不在论文图中嵌入动画或交互脚本。

## 9. 交付格式

- `PDF`（字体嵌入、矢量）+ `SVG`（文本可编辑或声明转曲）+ `PNG 300/600 DPI` + 复现脚本 + 图注文本。
- 物理宽度与目标栏宽误差 ≤1%；PDF 页面尺寸可核验。
- `viz-audit` 检查字体嵌入、DPI、WCAG、色盲 ΔE、白边/裁切。

## 10. 来源口径

- 写明数据来源、版本/日期、样本量、缺失与剔除规则。
- 统计检验名称、效应量、CI 与 p 值来源必须可追溯。
- 不把商业数据脱敏说明省略；不伪造“预注册”或“随机化”。

## 11. 无障碍

- 灰度打印完全可辨识；附原始统计汇总表或补充材料。
- 色盲模拟下系列可区分；颜色 + 线型/点型双重编码。
- 文本对比度 ≥4.5:1；图注不依赖颜色指代。

## 12. 专项禁令

- 严禁编造 p 值、样本量或显著性。
- 严禁 Jet/Rainbow 连续色标。
- 严禁 3D、装饰性阴影、渐变背景。
- 严禁截断柱状图基线或隐藏不显著结果。
- 严禁把商业 KPI 话术写进论文图。

## 渲染映射（viz-python）

```python
WIDTH_MM = 89 or 183
LAYOUT = "clean_open"        # 或 framed_journal
PALETTE = "okabe_ito"
FORMATS = ("pdf", "svg", "png")
DPI = (300, 600)
CITE_MM = None               # 按上页宽度决定是否放大字号
```

- 只改 PARAMS 与图注；不删除浅填深边、误差棒、零基线、n 标注。
- 图内标题置空时，用 `panel_label` 与外部图注补足信息。
- 渲染后必须 `check_recipe_fidelity` + `audit_export` + `ViewImage`。

- [ ] 灰度打印可区分；色盲模拟可区分。
- [ ] n、误差定义、检验、缺失/剔除说明齐全。
- [ ] 无编造显著性；无 Jet/Rainbow。
- [ ] 面板标号、字号、线宽一致。
- [ ] 图注独立可读，不依赖正文。
