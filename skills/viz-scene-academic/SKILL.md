# viz-scene-academic：科研出版级差分

本 Skill 不重复渲染代码。它只覆盖 `viz-core` 基线的 12 个场景槽位，最终由 `viz-python` 执行；若当前只勾选场景 Skill，先转 `viz-python`。

## 一、何时使用

- 目标为期刊/会议投稿、学位论文、科研报告插图；
- 需要单栏 85–89 mm 或双栏 175–183 mm 的物理尺寸；
- 需要报告样本量、误差棒定义、显著性检验与灰度打印可读性；
- 需要 PDF 矢量、可编辑 SVG、300/600 DPI PNG 与复现脚本。

不要用于：经营驾驶舱、董事会汇报、新闻信息图、在线交互地图。

## 二、标准工作流

1. **确认投稿约束**：期刊、栏宽（单/双栏）、最大高度、字体、线宽、是否黑白打印、是否要求可编辑 SVG。
2. **确认统计口径**：n、误差定义（SD/SEM/95% CI）、检验名称、显著性阈值；上游未给出时阻塞提问，不编造 p 值。
3. **读 `scene-delta.md`**：逐条应用 12 槽位；缺省值见下方。
4. **调用 `viz-python`**：按数据形态检索配方；优先箱线/散点、云雨图、森林图、火山图、KM、ROC、多面板。
5. **设置物理参数**：`WIDTH_MM=89` 或 `183`；`LAYOUT="clean_open"`（L 型轴）或 `framed_journal`（闭合框）；字号 6–8 pt；线宽 0.5–1.5 pt。
6. **导出与核对**：PDF + SVG + PNG 300/600；跑 `viz-audit` 检查字体嵌入、物理宽度、WCAG/色盲；`ViewImage` 目检中文、裁切、显著性括号与图例。
7. **图注独立**：图内不放“大标题”；图注写清 n、误差定义、检验、缺失/剔除与数据来源。

## 三、缺省参数

| 项 | 缺省 |
| :--- | :--- |
| 单栏宽 | 89 mm |
| 双栏宽 | 183 mm |
| 字体 | Arial / Helvetica / 宋体 / 黑体；`font.family` 有序回退 |
| 正文字号 | 7 pt（最小 6 pt） |
| 线宽 | 0.75 pt（0.5–1.5 pt） |
| 轴 | 左/下 L 型；刻度朝外；默认无背景网格 |
| 色板 | Okabe-Ito / 色盲安全；叠加线型、点型或纹理 |
| 导出 | PDF + SVG + PNG 300/600 DPI + 复现脚本 |

## 四、必须检查

- [ ] 物理宽度与目标栏宽误差 ≤1%；
- [ ] PDF 字体全部嵌入；SVG 文本可编辑或已声明转曲；
- [ ] 灰度打印可区分系列（颜色不是唯一编码）；
- [ ] 误差棒定义与 n 在图注/图内明确；
- [ ] 显著性括号只画上游检验结果；无 p 值不编造；
- [ ] 不使用 Jet/Rainbow 连续色标；
- [ ] 缺失值、剔除异常值、真实零值分开说明；
- [ ] 面板标号 a/b/c 位置一致，字号统一。

## 五、边界

- 不把商业 KPI 语言（“增长引擎”“抓手”）写进论文图；
- 不用装饰性阴影、3D、渐变背景；
- 不把统计推断交给绘图脚本；
- 不擅自改变数据、平滑曲线或隐藏不显著结果。

详细 12 槽位见 `scene-delta.md`；渲染参数与配方检索见 `viz-python/SKILL.md`。
